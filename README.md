# 🐳 Docker Labs

> Uma coleção de laboratórios, projetos e estudos práticos sobre Docker, desenvolvida para compreender não apenas como utilizar Docker, mas principalmente como ele funciona por trás dos bastidores.

Este repositório reúne desde projetos simples até ambientes mais completos, documentando minha evolução em containerização, persistência de dados, redes, otimização de imagens e boas práticas utilizadas em ambientes reais.

O objetivo é onstruir uma base sólida de conhecimento em Docker e tecnologias relacionadas.

## 📚 O que você encontrará

* 🧪 Laboratórios práticos

# 🔥 Docker Intensive — 7 Dias

Um dos principais conteúdos deste repositório é meu desafio pessoal de aprendizado intensivo.

Após concluir um curso de Docker, me desafiei a dedicar sete dias exclusivamente ao aprofundamento dos conceitos, explorando desde os fundamentos até cenários mais próximos da realidade de produção.

Ao invés de simplesmente seguir tutoriais, cada etapa busca responder perguntas como:

* Por que essa funcionalidade existe?
* Qual problema ela resolve?
* Quando utilizá-la?
* Quais alternativas existem?

Cada dia possui sua própria documentação detalhada.

Este repositório foi criado para servir como uma documentação viva da minha jornada em Docker.
