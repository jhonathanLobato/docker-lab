Como foi mostrado, existem tipos de imagens e eu resolvi testar cada uma delas para saber a diferença.
- As imagens normal contém um sistema operacional linux(como ubuntu ou debian) completo e rodando por baixo,
elas possuem um sistema de arquivos mais completo.
- Imagens slim são mais compactas e levem possuem menos arquivos de inicialização e dependencias que a versão normal, 
o que torna essa imagem mais leve.
- Nas imagens alpine elas são ainda mais leves e possuem menos arquivos importantes do que as demais versões.

Cada tipo de imagem tem sua função e pontos positivos e negativos, a definição de melhor ou pior deve ser feita
analisando o projeto em si. As imagens alpine, por exemplo, podem apresentar mais erros do que as outras versões
isso porque ela possue menos arquivos de configuração instaladas em suas dependencias.
No geral, é importante analisar todas as opções para não usar algo muito pesado ou algo que apresente muitos erros.

Perguntas de Arquitetura
- Por que um Dockerfile possui instruções em ordem?
O docker executar cada instrução em ordem linha a linha, então as instruções e comandos devem ser escritos na ordem correta. um exemplo, a instrução FROM deve
ser o primeiro no arquivo(exceto por um ARG) já que ele é a base para saber qual imagem o ambiente deve iniciar, e depois definir diretorios de trabalho e runs.

- Por que não executar código diretamente?


- Qual diferença entre imagem e container?
O container é uma instancia em execução de um modelo, e a imagem é um modelo estático. Uma analogia é a imagem sendo uma receita de bolo e o container
sendo o bolo já feito. A imagem é um arquivo que contém as bibliotecas, dependências e arquivos que o container precisa executar. Essa é a ideia de isolamento

- Por que uma imagem é imutável?
As imagens são imuntaveis porque a configuração que é passada no arquivo são executados e no momento é criado, depois disso a imagem se torna apenas de leitura

- O que acontece quando altero apenas um arquivo?
Nada acontece, se você mudar um arquivo é necessário criar uma nova imagem para essas alterações valerem.
